# v7 紧凑评审候选：默认存储禁用，不可投产

本版保留 38×38 mm、顶面器件、140 个 1 mm 间距接口的目标，配置为 1 GB LPDDR4 + 16 GB eMMC，断电后二选一存储模式。用户进一步明确：同一核心板允许切换，TF 卡座位于底板，通过原 TF 边缘引脚连接；核心板只安装 eMMC，不包含 TF 卡座/卡片。目标是 eMMC HS200，以及现有固件有证据支持的 TF 默认/高速 25/50 MHz；没有宣称 TF SDR104。

## 当前实质变更

- 纠正后的 Samsung 供电极性继续保持：VDDF/VCC 接 3.3 V，VDD/VCCQ 接独立 1.8 V；131 个存储器电源/地球位逐一回归
- PMU PAD68 以同域启动连接定义高电平，PAD64 偏置为不触发状态，PAD70/71 仅作观测；私有 DVFS 总线仍需要启动状态、隔离和固件适配
- 采用现有固定输出降压器的 PG 信号、独立 VIN 丢失检测、延时内部复位和存储禁止门；外部 RSTN 保持输入角色，不向底板反向驱动
- R528 默认 DNP，R529 保持禁止状态。R561 给 eMMC I/O 供电，但默认不接通主机通路。R528 不是自动 OTP 检测器；错误装配仍可能使错误电压接通，必须先完成配置证据与实测
- NVT4858 只在 TF 分支：主机侧 1.8 V、卡侧 3.3 V；本版未加入 UHS 电压切换。跨开关/转换器的时序和负载仍需验证
- 新增本地 eMMC CMD 22 kΩ、DAT0–7 47 kΩ 上拉；CLK 和不使用的主机 strobe 各有明确候选偏置，后者不连接 eMMC H5
- VDDI 的 2.2 µF + 220 nF 来自 OLIMEX 同基本料号的 3.3 V VCCQ 实板参考/BOM。对本设计 1.8 V VCCQ 的适用性、有效容量和 ESR 仍未获 Samsung 规范确认
- 全部 390 个 K230 球位做了方向/电气类型审查，90 项修正保留 GPIO 复用、LPDDR4 DMI 与 DSI lane0 的双向能力；不能把裸输入或模拟偏置随意当成输出

- 全部 353 个 RAM/eMMC 球位继续核对，27 项方向修正已应用；ZQ 为模拟参考，VDDI 为只接稳定电容的模拟内部稳压节点，DMI/CMD 保留双向能力

## 检查范围

紧凑工程当前 18 页、244 个网表引用，排除逻辑边缘符号、4 个 DNP 选项和2个测试观测点后为237个拟装功能器件。当前 KiCad CLI ERC 为0，但这只是已建模连接与类型的检查，并非完整启动、SI/PI、保护或硬件测试通过。32项结构检查、16个稳态互锁组合和4个隔离开关状态通过。

另保存了带额外八路监测的 instrumented-reference 版本，其面积预算不满足当前目标，因此不作为紧凑核心板的选定方案。精密电源监测不是原模块已知功能要求；紧凑版本明确不提供逐路电压跌落均先于芯片最小工作电压被复位的保证。

## 机械状态

16个小IC实例已关联经过图纸/坐标/掩膜/钢网检查的封装。3个BGA的全部球心和方向已核对，但生产焊盘、叠层、逃线和半孔工艺仍未定稿。

完整BOM的密集0201小无源器件矩形预留面积约1028 mm²，对比暂定2 mm周边带以内1156 mm²。随后对全部 243 个物理预留矩形（含 DNP/观测点、不含逻辑 J1）完成了无重叠拼排；结果图见 engineering/mechanical/full-envelope-packing-study.png。该算法未约束去耦距离、开关电源回路、BGA 逃线、走线通道或热，所以仍不是 PCB 放置/布线通过。0402小无源器件情形几乎耗尽面积，因此器件选型/密度与工艺必须一起闭环。早期13个IC外形画布没有包含整个BOM，不能当成完整板的放置通过。
