# Official model availability and license gate

The official K230 product page links to hardware resources containing an IBIS model, dated2024-12-12. Its header identifies proprietary Canaan material and requires an applicable written license agreement for use. Public download alone does not establish that license.

No simulation was run and the model is not included in this archive. Establish the relevant written authorization before using or redistributing it. This note does not accept an agreement or authorize a vendor message.

Verified source page: https://www.kendryte.com/zh/resource/hdk_other,k230
