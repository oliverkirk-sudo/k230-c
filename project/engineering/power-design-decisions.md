# D0 补充：电源矩阵与待决设计

本文件比D0增加可计算的23个K230电源域基线，但仍不是已接线的电源原理图。

## 预算定义
`rail-budget.csv`逐行记录官方指南电源域电压/电流及原文行号。所有GPIO-bank暂按3.3V计算，这是预算假设，不是接口电压决定。排除LPDDR3和K230D内部DRAM专属行，避免把K230D电流套到外接Samsung RAM。

按指南各域电流与所列标称电压简单相加为9.01W。**这只是器件级设计分配和，不代表实测、典型、保证最大值或一定同时出现的模块功耗。** 没有包含Samsung外部RAM、eMMC、外供3.3/1.8V、损耗、时钟/无源、瞬态余量。不能据此指定整板5V电源额定值。

最终VIN预算需逐工作模式计算：P_IN = Σ(P_rail/η_rail) + 保护/辅助损耗；I_IN=P_IN/VIN_min。η随电压/负载/温度变化；线损、启动浪涌、外供输出和最高CPU/KPU DVFS电压必须纳入。每路还需阶跃负载模型，而非只检查连续电流。

## 可研究的调压器路线（未冻结BOM）
- TI TPS62826：官方3A降压，2.4–5.5V输入、可调0.6–4V，1.5×1.5mm封装；可作为CORE固定标称电压的候选，不能替代KPU推荐4A能力。资料：https://www.ti.com/product/TPS62826
- TI TPS62864：官方4A、I2C/DVS，0.4–1.675V输出，15球0.35mm节距WCSP。电压范围覆盖CPU/KPU低压调节，但增加BGA制造难度、地址/启动默认/上拉/供电时序/固件验证。资料：https://www.ti.com/product/TPS62864
- 这些只是比EA3059更明确的能力候选；尚未选完整订货号、L/C/R、环路/瞬态、EN逻辑和PG时序。不能把典型应用直接当成针对本板验证过的方案。

## 兼容性约束决定电源控制方案
CM-K230已引出大量GPIO。为I2C调压器随意占用外露GPIO会增加负载或改变功能，所以目前不指定任何“空闲I2C脚”。先核对原板电源控制/BSP与K230专用控制能力，再确定控制路径；没有可兼容路径时，必须明确性能/功耗模式边界或取得接口变更许可。

## 顺序图准备
约束有向边：VDD0P8_CORE→VDD1P8，VDD0P8_CORE→各VDDIO3P3_0..5，AVDD0P8_MIPI→AVDD1P8_MIPI，AVDD1P8_RTC→AVDD1P8_LDO（允许同时）。必须叠加Samsung RAM/eMMC厂商的顺序要求。没有数值时序数据时，不臆造RC延迟。

候选实现是PG/监督器控制的确定性使能，而不是假定所有EN并联上拉就安全。外部bank提前供电可能打破芯片先后顺序并反灌，仍需原模块/底板合同解决。

## 电源域到外围的待连接矩阵
1. LPDDR4 VDD1=1.8V，VDD2/VDDQ=1.1V；与相关K230 DDR域供电网络按参考实现配合
2. VDD0P8_DDR_CORE、VDD1P1_DDR_IO、VAA_DDR不得按相似名字接成K230D专有DDR脚
3. eMMC VCC选择3.3V域；VCCQ待与MMC0固定/可切换IO域核对，未在网表短接
4. VOUT_3V3/VOUT_1V8必须给出外部额定电流、过载保护和先后时序；官网标注3.3V最大300mA、1.8V最大100mA，应至少满足这一兼容要求；瞬态、过载/短路与总输入预算仍待设计
5. BANK0..5_VDDIO方向/内部连接待证据，不把它们同时接内部稳压与外部电源

输出额定来源：https://wiki.01studio.cc/en/docs/canmv_k230/intro/canmv_k230/#pinout （pin7/8，2026-09-30读取）。两路同时最大负载还需额外1.17W输出及其转换损耗，尚未计入9.01W SoC域分配和。
