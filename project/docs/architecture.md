# D0 架构与实现策略

## 系统分块（设计意图，非已经连接的网表）
VIN_5V（模块4/5/6）→保护/滤波→各数字核心电源、DDR电源、模拟电源和板载3.3/1.8V输出。
K230 VFBGA390 → LPDDR4 双x16通道（共32bit，1GB）。K230 MMC0 → 16GB eMMC，按主控HS200能力设计。其余140针接口按已验证的模块合同逐针保留。

建议分页：01接口与电气合同；02K230电源；03时钟复位启动；04LPDDR4数据/命令；05LPDDR4电源/去耦；06eMMC；07多路电源及顺序；08GPIO-bank电源与低速接口；09USB/MIPI/模拟接口；10测试点/制造要求。

## 电源设计决策
独立预算CORE、CPU、KPU和DDR，模拟域按噪声要求滤波/LDO隔离。完整料号及元件值暂不冻结。不要将照片中的EA3059直接定为合格方案：其资料给出每路2A连续/4A峰值、总输出小于10W，不能当作四路4A连续；1.8V GPIO也不能直接假定满足其EN高门限。

拟采用足够持续/瞬态电流余量的独立降压通道，保留CPU/KPU动态调压路径；仅固定电压需和目标频率及固件一起验证。还要计算外供3.3/1.8V负载、eMMC启动、电源效率和正面散热，不能仅加各域标称电流。

时序约束：VDD0P8_CORE先于VDD1P8与VDDIO3P3_0..5；AVDD0P8_MIPI先于AVDD1P8_MIPI；AVDD1P8_RTC不晚于AVDD1P8_LDO。具体上升时间、间隔、掉电、棕断、斜率及复位释放应转为可测时序图，尚未完成。

## RAM与eMMC
K4F8E304HB-MGCJ属于Canaan已验证LPDDR4列表，容量8Gb=1GiB；双通道各16bit，不是两颗512MB DDR3L。采用其完整球图和封装，并将K230球名、信号别名、DRAM球名、交换关系写入独立连接矩阵。切勿把DDR_DQ序号直接当成LP4通道位序。必须逐项复核参考设计交换与训练参数。

候选eMMC使用MMC0的8bit总线；主控上限按HS200，不能因器件支持eMMC5.1就宣称HS400。VCCQ选择与主控bank一致；未确认前不把它接至任意1.8/3.3V。启动默认、上下拉、复位、DAT0忙状态、下载和恢复流程要同时验证。

## 正面布局意图
优先保证K230与RAM距离、DDR回流/去耦和BGA逃线；再放eMMC和多路电源，最后优化外部接口。此处不冻结照片式位置，也不宣称38mm单面装配必然满足所有约束。底面可以有内层引出和线路，但不得放元件。

建议以8层有连续参考面的方案进行可行性评估（非已批准叠层）。由板厂提供铜厚、介质、最小线距、阻抗截面、HDI/过孔能力和半孔工艺；不能只写“8层”就视为可制造。DDR等长必须计入封装内走线，而非只看板上长度；数值限制从完整器件/官方约束图冻结后录入EDA。

USB、MIPI、DDR分别建立网络类和差分对，保持参考面连续，避免换层回流断裂；在核心板+底板整体通道上审核损耗和匹配。外部防护、电压和串阻归属必须写清，避免底板和核心板重复或遗漏。

## 热与调试
准备供电、复位、时钟和启动状态可探测点；测试点不得改变接口功能。最高目标频率/AI负载/外部负载同时运行进行热测试，并确认所需散热方式。未经测试，不声明满频或环境温度范围。
