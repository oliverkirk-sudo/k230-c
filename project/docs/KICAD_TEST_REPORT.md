## 如何理解这些检查
ERC仍有错误是因为接口没有内部电路。无器件的轮廓PCB获得0DRC，只能说明当前空轮廓没有报告违规。courtyard修复只改善配合封装装配检查，不解决半孔加工、DDR布线、BGA逃线、电源时序或TF/eMMC隔离。

## 继续设计前的具体问题
1. 官方TF边缘引脚与eMMC固件均指向MMC0；eMMC固件是1.8V/8bit/HS200。原模块在eMMC装配中的外部TF隔离/电压/使用限制须确认，不能把3.3V卡接到未确认的1.8V共享网络
2. 半孔孔径/镀层、实际板厚、叠层和制造公差未建立；现文件默认层数/厚度不是设计规格
3. DDR已有65信号端点候选及器件球图，仍需训练映射、完整供电/去耦/终端、版图与SI/PI审核
4. 两路对外电源按官网300mA/100mA要求设计；瞬态、过载、热和电源顺序未实测
