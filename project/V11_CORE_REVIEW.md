# v11：原生 eMMC 逃线试验与核心 PCB 导入

默认 R528 仍为 DNP，存储通路禁止。尺寸仍为 38×38mm、140 针、1mm 间距、顶面器件；外部 TF 卡座不属于本工程。此版本仍未完成整板布局布线，也未证明能启动或满足高温环境。

## 本轮真正完成的内容

1. 独立的 eMMC 原生 KiCad 试验保留全部 153 个焊球焊盘，含 29 个过孔、16 段走线。11 条 HS200 主机信号及 VDDIM 的局部引出有实际几何模型；电源、地平面与本地电容没有伪装为已完成
2. 该局部试验已在实际云端 KiCad GUI 打开并重新运行 DRC，截图见 docs/kicad-gui-test/v11-emmc-local-*.png，未忽略测试，也未做局部片段的原理图一致性检查。1,009 项独立原生文件检查通过。未屏蔽的 DRC 仍报告 17 处未完成电源连接和 32 项悬空警告；所声明的条件式线宽、间距、孔铜、焊环与阻焊规则下，没有其他名义几何违规。更严格规则的正向对照能触发预期错误
3. K230 最深的两个采样信号球有局部逃线见证；209 个已连接非电源信号/偏置端点的完整逃线仍未完成。这个结果不能推出八层一定够用，也不能推出必须 HDI
4. 高温核心工程新增部分 PCB 导入：38 个封装、341 个电气焊盘与主网表一致。除固定的核心板边缘铜结构外，37 个内部封装全部停放在板外，尚未放置；216 个元件引用仍缺少导入封装，内部走线为零
5. 19 个精密电阻位置采用 TNPW0402 条件候选与现行原厂推荐铜盘。VIN 检测分压仍为 88.7k/10k，总误差筛选预算改为 ±0.70%，名义约 4V 不变；校准、VREF、VBUS 电阻名义值与网络不变。寿命、实际校准脚功耗、阻焊和钢网资格仍待验证
6. 高温原理图最新 ERC 为 0 错误/0 警告；743 个电气类型、65 条 DDR 连接、131 个存储器电源/参考端点、62 个外露 GPIO，以及互锁结构/真值回归保持通过

条件工艺模型有两项故意引入错误的测试：指定焊盘侵入仍触发 3mil 规则，邻近外来走线仍触发 4mil 规则。没有通过忽略严重度或取消连接检查获得“零错误”。公开工厂能力不等于该叠层、半孔、刻蚀、阻焊、钢网与装配组合已获接受。

## 时序、电源与放置证据

- 已将全部 65 条实际 DDR 连接按 SoC 物理球位接到官方封装内长度表；64 条高速信号有数值，RESET 不在该表中。四个字节组、两个命令/时钟组数量有断言检查
- 官方 LPDDR4 建议使用到达时间约束：DQ 间小于 20ps、DQ/DQS ±10ps、命令/时钟 ±10ps。某个字节组的 SoC 封装内部长度差接近 5mm，因此不能只把 PCB 铜线拉成等长。Micron 封装延时与最终板级传播延时尚缺，未杜撰换算
- 固定供电剩余误差预算已列出，用于共同容纳压降、纹波、瞬态和未建模误差，不能重复使用同一余量。中央电源球与封装外顶面电容的投影距离不等于环路电感；仍需本地过孔、连续参考平面及 PDN 验证
- 更强 X7R 电容数量情形的启发式放置试验未能完成全部元件放置。它否定的是该次器件/位置/算法组合，不是用户的 38mm 目标。没有把无重叠矩形拼图当作可布线证明

## 保留而未擅自采用的替代件

Murata 0805 输出电容可降低区域需求，但精确料号的偏置、交流幅度、温度、老化综合有效容量仍需确认，未缩减现有电容组的有效容量要求。TPS628681A QFN 可减轻 0.085mm WLCSP 间距要求，但高温精度为 ±2%，并增加 MSL2 处理要求；现有 TPS628640B 保留，未声称性能等价或电容减少。
