# v6 变更与当前硬件状态

本版延续v5对危险eMMC供电映射错误的修复：VDDF=VCC闪存主电源接3.3V，VDD=VCCQ接独立VEMMC_IO。v4不得接线或制板。

-131个LPDDR4/eMMC电源及地球位自动回归全部匹配
-官方K230引脚工作簿和参考图支持14个LPDDR4模式不用引脚、4个单rank不用输出；Samsung H5为HS400专用输出，在HS200方案中明确不用
-17个稳压器经L/FB/0Ω供电路径被逐条追踪；另对外部5V输入/地返回作CAD电源声明，没有给VEMMC_IO或六个bank输入伪造来源
-TMUX模拟触点改为passive类型，TEST_EN为input，MMC0_STROBE为input；更准确的类型暴露了真实未驱动输入问题
-当前KiCad实际GUI及CLI均为14项：13错误、1警告，工程14页。静态隔离真值表4种状态和71个引脚连接回归通过

ERC从51降到14不代表硬件接近可生产。余下项目中有启动依赖：PMU默认需要PAD64长按或PAD68高电平，当前输入开路/下拉没有证明PMU启动；完整硬件复位和存储使能仍缺失。PAD68自动启动有官方寄存器依据，下一步应把同域偏置、PMU状态和隔离时序共同设计。

官方文档还显示SDIO0启动电压涉及不可逆OTP；普通冷选择焊盘不能自行改变它。未生成或烧写OTP。固定1.8V主机配TF电平转换是待审方案，不是已完成修改，也没有降低原定性能。

通用TPS386000监控候选的DDR阈值/迟滞与当前最差电源公差不相容，因而没有装成一个表面完整但不能保证启动的复位电路。确切eMMC CReg参数仍待制造商资料。完整PCB、封装、顶面放置、半孔工艺、SI/PI、热、固件与实测均未完成。
