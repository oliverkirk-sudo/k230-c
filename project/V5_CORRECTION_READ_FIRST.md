# v5 必须替代 v4：eMMC 供电映射纠正

v4 内部原理图把 Samsung 供电名称 VDD 和 VDDF 的含义反接。禁止据 v4 接线或制板。v5 已纠正：
- VDDF (VCC) = NAND 闪存主电源，接 VDD_3V3
