# v8 评审检查点：高温要求尚未满足，默认存储禁止

目标仍为38×38mm、顶面器件、140个1mm间距接口、1GB LPDDR4和16GB eMMC。用户明确要求同一板断电后切换；TF卡座在底板，通过原TF边缘引脚连接，不在核心板BOM或面积里。

新增环境要求：密闭环境，可能75–85°C；空气温度还是器件表面温度仍待明确。现有Samsung存储器85°C等级不能据此称为满足要求。X5R不能用作忽略热裕量的缩小封装办法。高温器件替代正在独立核对；尚未擅自把当前符号改名当成兼容件。

## 实际电路进展

- U90延时复位先进入独立100k节点，再由U91 SN74AUP1G17施密特推挽缓冲驱动SoC。外部RSTN仍是输入请求，不被内部输出反向驱动
- 弱上拉节点不再承受SoC漏电/内部上拉，亦不依赖旧开漏缓冲器未明确的释放漏电参数。保守通用I/O模型的有效供电静态筛选得到约522mV高、272mV低裕量；专用RSTN参数适用性和离散供电点解释仍需确认
- 旧的并联快速旁路已移除。TPS3808的MR响应150ns是典型值，不是保证上限；本版不宣称任意棕断保护
- 新增两个MIPI本地100nF，使每路模拟电源各两个，与参考C120/C121、C122/C123的数量一致
- Y2采用源BOM中的X322524MOB4SI候选及厂家建议焊盘；12pF参考负载电容仍需按寄生/起振测量调整
- U95 NVT4858HKZ正确封装为SOT1161-2，已有16焊盘、铜/阻焊/钢网及编号审核；不是SOT1174-1。保留其独立阻焊/钢网图形
- R561采用WFZ040200000ZE66低阻跳线候选，仍是条件式1.8V VCCQ供电，默认R528 DNP禁止主机通路

## 仍然阻止启动/投产的事项

1. R528默认DNP，存储禁止。需要正确板级OTP配置证据/读回和首次驱动验证；没有生成或烧录OTP
2. 同一不可逆OTP配置下，MMC0能否同时支持两种冷选介质启动尚未证明。参考板确有MMC0 SD卡启动，但不能据此保证新翻译链的同OTP双介质自识别；两个运行时镜像不能修复ROM阶段不匹配
3. Samsung VDDI参考电容源于3.3V VCCQ板，当前1.8V条件仍未获其规范确认
4. 高温器件等级、有效容量、局部温升及封闭环境热通路；当前小封装面积估计不能证明高温合格部件能放下
5. 完整BSP、PCB局部去耦/逃线/回流、SI/PI、热、启动和全部接口实测

最新基线为245个物理矩形无重叠拼排，密集预留1029.75mm²；0402情形1159.23mm²已超过暂定1156mm²内部面积。此基线仍有未选定电容参数，不能当成可生产BOM。原始v7几何拼排只是矩形研究。源曲线支持的X7R情形显著增加面积，部分低于总面积的方案也未被现有启发式成功拼排；既不能宣称放得下，也不能据此证明38mm不可能。详见engineering/mechanical的有日期情形报告。
