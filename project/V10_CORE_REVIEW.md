# v10 核心板评审进展

保留 38×38mm、140 针、1mm 间距、顶面器件、1GB LPDDR4、16GB eMMC 和断电切换外部 TF 的范围。R528 默认 DNP，存储通路仍禁止；本工程未证明可以启动或制板。

## 本轮落图与验证

- 高温候选四个逻辑器件改用经过原厂封装图审核的 Nexperia GW 标准封装，不再等待未核实的微型 GX 土地图。铜、阻焊、钢网几何与独立检查记录一并保留
- 四路固定稳压反馈电阻整体缩小十倍，底阻 10k；对应 Cff 同时增至 1.2nF。名义电压不变，反馈偏置误差缩小，新增分压损耗约 0.380mW。0.70% 总电阻误差只是条件式筛选预算
- 高温候选仍为 18 页、254 个引用、247 个拟装功能器件。当前 CLI ERC 为 0 错误/0 警告；743 个电气类型、65 条 DDR 连接、131 个电源/参考端点、62 个外露 GPIO、互锁结构和真值表持续回归
- 缩短了图框标题，并检查本轮导出的首页与复位页。包内 high-temp-* GUI 截图属于 v9，不能当作 v10 的 GUI 检验

## 新的边缘制造提案

cad/castellation-proposal 是独立的可编辑机械提案，本文件自身为冻结的机械提案。另有 cad/edge-bound-seed，将全部 140 个焊盘逐一绑定到当前高温原理图 J1 网络；J1 已设为板上铜结构，仅从采购 BOM 排除。该 PCB 种子没有内部器件或走线，不能作为整板网表一致性通过。保留所有触点位置，拟用 0.50mm 名义成品半孔、沿边 0.80mm/向内外 1.80mm 椭圆铜盘。原始 STEP 确实含 140 个名义 0.50mm 边缘开孔；这支持形状/位置，不支持钻具、镀层或公差。

触点与原底板椭圆焊盘的偏移及重叠已计算。提案的 1.30mm 元件预留带来自铜盘、阻焊和装配预算，得到条件式 1253.16mm² 内区。它并不等于已经可布线的面积。公开工厂规则互有差异，该组合不能当作通用标准工艺通过。八层叠层、钻孔到铣边配准、阻焊桥、四边拼板支撑、BGA 逃线及装配仍须联合确认。

## 物理可行性仍需完成

当前高温版本的乐观小件面积为 1041.62mm²；所列 0402 预留为 1174.42mm²。电容实料 X7R 方案会增加面积：已有研究同时考虑直流偏置、交流幅度、温度和条件式老化预算，较紧的方案最弱有效容量余量仅 2.74%，不能作为已合格 BOM。较宽余量方案增加器件数。没有靠删去必要旁路或假定 X5R 可耐本环境来宣称放得下。

三颗大 BGA 仍无释放的生产土地/逃线方案。Micron CSN-33 原厂页面本次返回拒绝访问，未继续绕过；未用封装球径冒充 PCB 焊盘尺寸。完整放置、高速走线、供电回路、热路径与高温容量还没有得到实物验证。

## 继续保留的关键门槛

85°C 密闭空气仅是保守筛选边界。存储器升温余量、K230/稳压器局部温度、NVT4858 与晶体的 85°C 等级仍限制资格判断。Micron DDR 训练及高温刷新需移植验证。OTP 首次驱动电压和同一 OTP 下 MMC0 对两种介质的启动协议仍需确定；未执行任何 OTP 操作。

官方 IBIS 未运行或打包，需适用许可。没有外部上传、采购、制造订单或外设设计。
